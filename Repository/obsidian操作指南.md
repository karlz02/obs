# 插件指南

| 插件                           | 简介                               |
| :--------------------------- | :------------------------------- |
| **BRAT**                     | 通过 GitHub 链接安装未上架的 Beta 插件       |
| **Style Settings**           | 调整主题、插件和代码片段的 CSS 变量             |
| **Dragger**                  | 像 Notion 一样拖拽段落、标题、列表等块来重新排列内容   |
| **Simple Columns**           | 在笔记中创建多列布局，支持自定义列宽               |
| **Quiet Outline**            | 更强大的大纲面板：不自动展开、支持 Markdown 渲染和搜索 |
| **I18N**                     | 插件国际化工具，助力插件界面汉化                 |
| **Colored Bases Properties** | 为 Bases 数据库中的属性列表和公式属性添加颜色       |
| **Vertical Tabs**            | 将标签页垂直显示，支持分组和整理标签               |
| **Open Tab Settings**        | 自定义标签打开方式：默认新标签打开、防止重复标签等        |
| **Realistic Sticky Notes**   | 逼真的实体风格便利贴                       |
