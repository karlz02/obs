# 如何选择英雄对位
嫦娥  法坦
	我感觉只要对面阵容突脸，肉，且第一时间爆发是秒不掉你的情况下出
		比如 赵云 戈娅 夏洛特 刘邦 火舞 | 这局对面认真来说是没有高爆发英雄的
			1.火舞（突脸爆发一波流）：大家眼里的高爆发控制英雄，其实现在火舞都走工具人流派了，前期利用闪现来开人打节奏，前中期要跟火舞盯对位，不然利用其前期高机动性加开团能力很容易把队友打崩，拖到后期嫦娥的作用是比火舞大的，一波流和持续流相比的话；
			2.赵云（突脸半爆发一波流）：赵云只会出黑切一件攻击装，只是大招给的击飞太过于惊吓导致，让大家觉得赵云伤害高，与火舞一样，顶住前中期赵云的强势期（战士打野的优势），后期嫦娥也是非常好打赵云的；
			3.戈娅（突脸无爆发持续流）：这英雄一般都走半肉法球流，后期没伤害，对嫦娥来说，非常好打；
			4.夏洛特 刘邦：对抗路和辅助这两个肉，不需要解释了，只是要小心刘邦的前期全图可飞的节奏；
			总结1：主要看对面中射野的属性，这把他们三个都是突脸的阵容，且控制是短时控制，出嫦娥盯住前中期，后期自动解锁胜利；
			反思1：如果出诸葛亮可以打吗？-首先刘邦这英雄非常克制诸葛亮，诸葛亮边路带时的第一要求就是有足够的钱去对位对面的带线边或者刺客从而辐射优势给队友，但是有了刘邦这个因素，边路带线是打不很难打过的，且诸葛亮的发力期是在中期，也就是4到15分钟这段时间，这个时间就是对面阵容的强势期，硬碰硬的话，还是对面优势非常大，且需要队友补起码2个控制，对阵容的要求太高了，能赢只有2中可能，大优势或者惨胜；
			反思2：如果出猫咪可以打吗？ -首先猫咪这个英雄非常害怕突脸控制，身板实在太脆了，只要对面有意识切猫咪的话，对面的阵容只要顶上来，猫咪是无能为力的，猫咪的优势就是前中期利用消耗爆发来帮队友抢经济，这把前期猫咪可能稍微好打一点，中期开始，对面开节奏，猫咪无解，而且猫咪没法对位火舞；



诸葛10分钟之后就得猥琐打法了，均势或者逆风，不要想着单带跟对面单挑，这时候已经过了诸葛亮的强势期且是对面的优势，只能跟着队友打团，对面位置明漏的情况下可以去偷偷带线，但是不要想着单挑，这时候只能看队友能不能开团，队友开不了只能慢性死亡下一把了，此时的胜负和诸葛亮已经没有关系了
诸葛强势期就是4分钟到10分钟，这时候要多找机会，不要害怕，这时候害怕，后期更打不了
