### 切入点2：要证明 $A = O \iff A$ 中元素全为 $0$（零矩阵） 

> [!answer]
> 第一反应：$AA^T = O \implies$ 解出主对角线元素平方和为 $0$
>
> 即：
> $$\left. \begin{array}{l} a_{11}^2 + a_{12}^2 + \cdots + a_{1n}^2 = 0 \implies a_{11} = a_{12} = \cdots = a_{1n} = 0 \\ a_{21}^2 + a_{22}^2 + \cdots + a_{2n}^2 = 0 \implies a_{21} = a_{22} = \cdots = a_{2n} = 0 \\ \quad \cdots \\ a_{n1}^2 + a_{n2}^2 + \cdots + a_{nn}^2 = 0 \implies a_{n1} = a_{n2} = \cdots = a_{nn} = 0 \end{array} \right\} \implies A = O$$
