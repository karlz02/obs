# Note Meta Time（笔记创建时间·自研）

> [!quote] 在每个文档第一个 H1 标题下方，淡化显示该文档的创建时间。

## 它是干什么的（人话版）

在每个文档第一个 H1 标题下方，淡化显示该文档的创建时间。

## 具体能做什么

- 自己写的插件：阅读模式下，文档第一个一级标题下方显示「2026年8月9日，星期日  7:04」。
- 字体淡化、不可选中、不可修改；时间不进文件、不进 frontmatter，纯视图层显示。
- 数据源：优先文件系统 birthtime（真正创建时间），回退 ctime。
- 注意：目前仅阅读模式生效（编辑模式的 CM widget 渲染在 H1 空行边界不稳，已移除）。
