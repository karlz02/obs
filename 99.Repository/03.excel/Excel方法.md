# Excel 方法整理

## 1. 统一多个列的列宽

在 Windows 下，可以用以下方法把 A、B 列（或多列）设置为完全一致的宽度。

### 方法一：快捷键输入精确列宽

1. 选中 A、B 列，或需要统一宽度的多列。
2. 依次按下 `Alt → H → O → W`。
3. 在弹出的“列宽”输入框中输入数值（例如 `15`），按 `Enter` 回车。

### 方法二：鼠标拖动同步调整

1. 单击顶部的列标 `A`，按住鼠标左键向右拖到 `B`，同时选中 A、B 两列。
2. 将鼠标移动到 A、B 之间的分界线（也可以移动到 B、C 之间）。
3. 当光标变成双向箭头后，按住左键拖动并松开，A、B 两列的宽度就会变得完全一致。

### 自动适应最长文本

1. 选中 A、B 列。
2. 依次按下 `Alt → H → O → I`。
3. Excel 会根据单元格中最长的文字（例如 `Aug 17~Aug23`）自动调整列宽。

## 2. 批量合并多列的第 1、2 行

在 Windows 下，如果要把 B、C、D、E 等各列的第 1 行和第 2 行批量合并，可以使用以下方法。

### 方法一：复制格式粘贴

1. 单击已经合并好的 A 列单元格，按 `Ctrl + C` 复制。
2. 选中 `B1:H2` 区域（可以按住 `Shift`，配合方向键框选）。
3. 依次按下 `Alt → E → S → T`，然后按 `Enter` 回车。

也可以使用：`Ctrl + Alt + V → T → Enter`。

### 方法二：格式刷拖选

1. 单击已经合并好的 A 列单元格。
2. 点击“开始”菜单中的“格式刷”（小刷子图标）。
3. 从 `B1` 向右拖到 H 列后松开鼠标，所有列的第 1、2 行即可完成合并。

## 3. 设置字体、字号和颜色

### 设置字体

选中目标区域，依次按下 `Alt → H → F → F`，输入 `Arial` 或 `Calibri`，按 `Enter` 回车。英文使用这两种字体会更工整、硬朗。

### 调小字号，避免文字溢出

选中目标区域，依次按下 `Alt → H → F → S`，输入 `9` 或 `10`，按 `Enter` 回车。

### 将整列设置为米黄色底色

适合大部分内容为 Study 的区域，可先统一刷成浅黄色：

1. 选中 `A3:A26`。
2. 依次按下 `Alt → H → H`。
3. 用键盘方向键选择“浅黄色 / 奶黄色”（标准色板中的浅橙色或浅黄色），按 `Enter` 回车。

### 将文字改为纯白色

选中目标区域，依次按下 `Alt → H → F → C`，用方向键选择“白色”，按 `Enter` 回车。

### 清除单元格的全部格式

选中需要清除格式的红色单元格，依次按下 `Alt → H → E → F`，即可一键清除该单元格的所有格式。

## 4. 添加边框

选中需要添加边框的区域，依次按下 `Alt → H → B → A`。

> [!tip] 效果
> 每行之间会出现清晰的细黑横线，便于区分各行内容。

## 5. 将数据水平、垂直居中

### 示例：设置周一至周日的数据区域

1. 选中 `B27:H36`，即周一至周日的数字和百分比区域。
2. 水平居中：依次按下 `Alt → H → A → C`。
3. 垂直居中：依次按下 `Alt → H → A → M`，使内容位于单元格正中央。

## 6. 分钟和小时互相换算

- 分钟转换为小时：如果 `A1` 中是分钟（例如 `70`），输入 `=A1/60`，结果显示为约 `1.17` 小时。
- 小时转换为分钟：如果 `A1` 中是小时（例如 `1.3`），输入 `=A1*60`，结果显示为 `78` 分钟。
