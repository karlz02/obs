# 什么样的题可以放到错题本里面？
**第一类：基础没学会导致的错**  
比如公式不会、概念不懂、例题都没看明白。  
这种不用进错题本，回去补基础就行。

**第二类：计算粗心导致的错**  
比如符号写错、少写平方、代数化简错。  
这种也不用全进错题本，只在旁边标一句“计算易错”即可。

**第三类：有价值的错**  
这种才进错题本。标准是：

- 我看了解析后发现这题有固定方法
- 我下次很可能还会错
- 它暴露了一个重要概念混淆
- 它代表一类题型
- 它有一个明显的**“题眼 → 方法”**关系

# 放到错题本里面的题该怎么处理？
核心宗旨：4个为什么？（考点、切入点、错因、如何避免）
	1.这个错题的考点是什么？
	2.这个错题为什么要这么做？ 
		比如这个题要用泰勒，那为什么要用泰勒呢？ 是哪个条件或者哪个标志指引着我去用泰勒，
		说到底要去说服自己。
	3.我犯了什么错？
		是我哪一步没有想到或者哪一步想错了，犯了什么错？
	4.我现在有没有找到避免这个错误的方法？
		下一次遇到这个问题，我应该往哪个方向走。

# 错题怎么分类
**A类：公式定义题**  
看到题就知道考什么，基本是：

```
定义
公式
基本性质
一步计算
```

错了说明基础没记住，不要焦虑，补基础。

**B类：固定套路题**  
这类是考研数学最重要的主线。它不是一步出答案，但方法很固定。

```
看到题眼 → 想到方法 → 按步骤做
```

比如：

```
二元函数极值
二重积分常规计算
反常积分敛散性
协方差/相关系数
二次型规范形
```

**C类：固定套路绕一个弯**  
本质还是常规套路，但题目会拐一下：

```
多套一个条件
多个知识点接一下
有个容易掉的坑
需要先变形再套方法
```

比如：

```
含参变上限积分
矩阵特征值选择题综合
尾概率条件概率辨析
幂级数里带未知常数
```

**D类：一眼不知道怎么做**  
这类通常是：

```
综合度高
步骤长
入口不明显
要把多个知识点串起来
前期容易卡很久
```

不是说永远不学，而是第一轮不要让它拖死你。

所以你的版本可以直接作为分类口诀：

```
A：看见就套
B：看见题眼就套
C：先绕一下再套
D：先看不出套什么
```

这个特别适合你用来分类错题。

处理方式也很清楚：

```
A：补公式定义
B：进主线反复练
C：第二轮重点攻
D：后期攻坚/先标记
```

你之后遇到题，就问一句：

**这题是直接套、看题眼套、绕一下套，还是我完全不知道套什么？**

这个判断比“简单/中等/困难”有用多了
