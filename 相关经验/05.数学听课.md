要复盘，但**不是一次复盘做完**。数学最稳的是三段式：

```
课后马上：热回顾
当天晚上：正式复盘
第二天：短复盘
```

**1. 听完课后马上做什么？**

课后立刻做 **10-20 分钟热回顾**，不要拖到晚上才第一次想。

这个阶段不需要整理得很漂亮，只做三件事：

```
1. 这节课讲了哪几个知识点？
2. 每个知识点解决什么问题？
3. 哪里没听懂、哪里感觉会错？
```

比如听完行列式，就马上写：

```
行列式
- 定义：二阶、n 阶、余子式、代数余子式
- 性质：互换变号、提因子、倍加不变
- 方法：化零降阶、按行列展开
- 题型：普通计算、代数余子式、特殊行列式
```

这个叫“防止刚听完就散掉”。

**2. 当天晚上做什么？**

当天晚上做 **正式复盘**，大概 40-60 分钟。

顺序建议：

```
第一步：闭书回忆知识框架
第二步：打开讲义补全定义、公式、性质
第三步：做对应例题或基础题
第四步：整理当天错题
```

错题不要只写答案，要写这三行：

```
错因：我为什么错？
正确方法：这题应该怎么想？
下次提醒：看到什么特征要想到这个方法？
```

比如：

```
错因：副对角行列式忘记符号。
正确方法：结果前面要乘 (-1)^{n(n-1)/2}。
下次提醒：看到副对角，不要直接乘元素。
```

**3. 第二天还要不要复盘？**

要，但第二天不是重新整理一遍，而是 **10-15 分钟短复盘**。

第二天主要做两件事：

```
1. 空白纸默写昨天的知识框架
2. 重做昨天错题或同类型题
```

重点是“关上答案还能不能做出来”。

如果第二天你能默出来、错题能独立做出来，这个知识点才算开始变成自己的。

**最推荐的时间安排**

```
听课后 10-20 分钟：
快速回顾框架，标记不懂点。

当天晚上 40-60 分钟：
正式整理知识点 + 做题 + 错题复盘。

第二天 10-15 分钟：
默写框架 + 重做错题。

周末 30-60 分钟：
把这一周错题按题型归类。
```

一句话：  
**听完课后马上做轻回顾，当晚做正式复盘，第二天必须做短复盘。**  
数学不是靠“当时听懂”，而是靠第二天还能不能自己写出来、做出来。
