- [ ] 单词笔记的核心原则：只记「你加工过的内容」

| 不要记            | 要记             |
| :------------- | :------------- |
| 词典里的完整释义       | 真题考过的那个意思      |
| 词典例句           | 真题原句 + 你自己造的句子 |
| 词根词缀（除非你主动分析过） | 你自己发现的规律/联想    |
| 所有搭配           | 完形和阅读里反复出现的搭配  |

**检验标准**：如果你记的内容可以直接从词典里复制粘贴，那这条笔记**不要写**。
- [ ] **低频词快速扫完混眼熟，核心词回头深度加工，真题立刻开始做。词汇学习的终点在真题里，不在APP的打卡数字里。**
- [ ] 在APP里记笔记 = 提前预判真题会怎么考 → **效率极低，且容易记一堆不考的东西。**
- [ ] 所以APP只是你的**「筛子」**，把5500个词快速筛一遍，让高频词在你脑子里有个印象。真正决定「哪些高频词需要记笔记」的，是真题。
