
---
**continent**
```
 [n] 大陆：Africa is the world's hottest continent. 非洲是世界上最热的大陆；
```
 **continual**
```
[adj] 重复的，持续不断的：He was in a continual process of rewriting his material. 他一直在不断地改写他的材料; 
```

---



**broad**
```
 [adj] 宽广的：we need a broad range of ideas. 我们需要广泛的思路。
固定搭配：
	broad daylight 光天化日；
	in broad terms 概括地来说；
```

**abroad**
```
[adv] 在国外，去国外：go abroad 出国
```
> [! ]
> 记忆窍门：
> - 里面藏着broad，出了国，天地变宽广了；

**board**
```
[n] 
	1.板子/牌子：surfboard 冲浪板；
	2.董事会：The board of directors approved the budget. 董事会批准了预算。
	3.伙食：room and board 食宿；
[v] 登（上交通工具）：It‘s time to board the train. 该上火车了。
```

> [! ] 
> 记忆窍门：
> - r在o前面的是broad：r在前，联想road，道路很宽广；
> - o在r前面的是board：o在前，联想officer（官员），在董事会里面的官员；
> 

**aboard**
```
[adv] 登上（交通工具）：we went aboard. 我们上船/飞机了；
[preposition] 在...的上面：he is aboard the train. 他在火车上；
```
> [! ]
> 作为副词，通常放在句尾，前面需要一个“动作”动词，比如go,get,come;
> 作为介词，后面接交通工具；
---


**idea**
```
[n] 想法，主意：I have no idea where he is. 我完全不知道他在哪；
```
**ideal**
```
[adj] 理想的,最完美的：The weather is ideal for a picnic today. 这天气对于今天的野餐是理想的；
[n] 崇高理想，完美标准：We must live up to our ideals. 我们必须不负我们的理想；
```
---
**desirable**
```
[adj](形容事物)值得拥有的，理想的：It's desirable that you interest yourself in your work. 对自己的工作感兴趣是令人向往的；
```
**desirous**
```
[adj]（形容人）人感到渴望的，想得到的：He was desirous of finding a quick solution.
他急于找到一个快速的解决方案；
```
> [! ]
> desirous是一个比较正式且书面化的词，几乎总是用在`be desirous of + 名词`结构中；
