**不要抄完整步骤到错题本里。** 抄步骤是错题本最大的陷阱——你抄的时候觉得自己懂了，过两周再看，只是一堆陌生的式子。

给你一套清晰的「听讲→记录→整理」流程：

---

## 一、听讲时：用草稿纸，不是错题本

老师讲解时，你拿**一张草稿纸**跟着写：
- 可以完整记录老师讲的过程
- 用红笔随时标「这里我不懂」「这步很巧妙」「这步怎么想到的」
- 这是**听课草稿**，听完可以扔，不需要漂亮

**错题本在这个阶段是空白的**，不要边听边往错题本上抄。

---

## 二、课后：先独立做，再进错题本

听完课后，**合上所有资料，拿一张白纸自己重新做一遍**。

- 做出来了 → 说明你至少当下掌握了，可以整理进错题本
- 没做出来 → 看草稿纸提示一下，再做，直到能独立做出来

**只有独立做出来后，才有资格进错题本。** 否则这道题应该回到「类型1」重新学知识点，而不是假装会了记在本子上。

---

## 三、错题本写什么？（按你的四本分类）

**原则是：只记录「你当时不会的部分」，不记录「你本来就会的部分」。**

### 类型1（不会知识点）

```
【题目】（抄题干或贴题号）
【涉及知识点】函数单调性与导数的关系
【我当时不会的点】不知道f'(x)>0能直接推递增，想复杂了
【知识补漏】（用自己的话写，不要抄书）
    导数大于0 → 函数递增；导数小于0 → 函数递减
    注意：是严格大于/小于，等于0的点不影响整体单调性
【关键第一步】求导后令f'(x)=0找临界点
【完整答案】（可选：只写结果，不写过程，或写极简框架）
```

### 类型2（没思路）

```
【题目】
【题目特征】含参不等式恒成立 + 定义域为R
【我当时想歪了】想直接求最小值，忽略了参数分离更简洁
【正确切入点】看到"恒成立"→先尝试分离参数，把a和x分开
【关键第一步】原式变形为 a > g(x) 对任意x∈R成立
【思路口诀】（自己总结）恒成立，先分离；分不了，再求最
```

### 类型3（算不出/卡在某步）

```
【题目】
【卡壳步骤】从 "lnx - ax = 0" 到 "a = lnx/x" 的变形
【技巧名称】参变分离
【触发条件】等式一边含参数a，一边含x，且容易分离
【这步的变形过程】（只写这1步，前后不写）
    lnx - ax = 0  →  lnx = ax  →  a = lnx/x (x>0)
【同类题号】（如果有）练习册P23第5题也是这步卡壳
```

### 类型4（不规范）

```
【题目】
【标准采分点】
    ① 写出定义域（1分）
    ② 求导并化简（2分）
    ③ 列表分析单调性（2分）
    ④ 得出结论（1分）
【我漏的得分句】"由题意可知，函数定义域为(0,+∞)"——我每次都忘写
【我的冗余步骤】求导后展开了三次，其实可以因式分解直接看出零点
【规范模板】（自己整理一个极简版）
    1. 定义域：...
    2. f'(x) = ... = ...（因式分解）
    3. 令f'(x)=0，得x=...
    4. 列表...
    5. 综上...
```

---

## 四、为什么不要写完整步骤？

| 你抄了完整步骤 | 你只写关键信息 |
|---|---|
| 复习时看到一大篇，不想看 | 一眼扫完，重点突出 |
| 遮住答案重做时，不小心瞥到下一步 | 只有框架，必须自己补全计算 |
| 大脑被动接受，不思考 | 大脑主动填补空白，真正内化 |
| 错题本越记越厚，变成负担 | 错题本精简，愿意反复看 |

---

## 五、一个检验标准

整理完一道错题后，问自己：

> **如果一个月后我只看错题本上的记录，能不能在5秒内想起这道题的关键点，并且独立把题重新做出来？**

- 能 → 记录合格
- 不能 → 说明你还是抄了太多无关步骤，或者没提炼出真正的卡壳点

---

**总结一句话：错题本是「地图」，不是「导航语音」。** 地图只标关键路口，不会把每一步油门怎么踩都写下来。你平时做题时，完整步骤写在哪里？草稿纸、练习册、还是另一个笔记本？
