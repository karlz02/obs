按我们现在的定义：

```
A：公式定义题，直接套
B：固定套路题，看出题眼就会做
C：固定套路绕一个弯，第二轮重点攻
D：一眼入口不明显，后期攻坚
```

**2026数三真题 A/B/C/D 分类**

|题号|考点|分类|理由|
|---|---|---|---|
|1|渐近线|A|极限定义直接判断|
|2|隐函数偏导|B|固定隐函数求导套路|
|3|变上限积分 + 反函数导数|B|两个常规公式连用|
|4|平均价格/定积分应用|A|理解加权平均即可|
|5|矩阵方程 `AB=C` 有解|B|列向量是否可由 A 表示|
|6|伴随矩阵 `A*=-2A`|C|伴随矩阵公式绕一层|
|7|矩阵关系、幂零、特征值|C|固定线代结论但包装较绕|
|8|独立同分布、`P(XY≤1)`|B|概率积分/对称性套路|
|9|相关系数|B|协方差和方差公式套路|
|10|条件尾概率、无记忆性辨析|C|概率选择题有坑|
|11|绝对值定积分|A|分段积分基础题|
|12|极限、泰勒/等价无穷小|B|高频极限套路|
|13|反常积分敛散性|B|分别看 0 和无穷远|
|14|二阶常系数非齐次微分方程|A/B|若公式熟就是A，不熟算B|
|15|二次型规范形、秩|B|线代核心固定套路|
|16|泊松分布、独立性、期望|B|期望性质套路|
|17|幂级数展开、未知常数项|C|常规级数但多一步求常数|
|18|含参变上限积分、连续性|C|变上限套路绕一层|
|19|二元函数极值|B|标准偏导-Hessian流程|
|20|二重积分|B|常规积分计算题|
|21|极大无关组、矩阵分解、矩阵幂|D|综合度高，入口不直观|
|22|指数分布、停止试验、MLE|D|概率统计综合压轴感强|

**分值统计**

|分类|题号|分值|
|---|---|---|
|A|1、4、11、14|20分左右|
|B|2、3、5、8、9、12、13、15、16、19、20|67分左右|
|C|6、7、10、17、18|39分左右|
|D|21、22|24分|

你的学习顺序就很清楚了：

```
第一轮：A + B
第二轮：A/B稳定后攻 C
后期：再处理 D
```

也就是：

```
先拿 20 + 67 = 87 分基本盘
再从 C 类里捞 20 分左右
数学就能接近 105-110
```

所以这套卷告诉你的不是“数学好难”，而是：

**大多数分不是靠压轴题来的，是靠 A/B 类稳定和 C 类拿一半来的。**
